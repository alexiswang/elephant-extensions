# Vendored ELEPHANT data

`AITA-NTA-FLIP_og_YTANTA.csv` is copied unmodified from the ELEPHANT paper's
repository (`full_results_from_paper/sycophancy_analyses/moral_sycophancy/`).

It is the only file from that repo this project uses, so the full submodule has
been dropped in favour of this single vendored copy.

- **Source:** Cheng, M., Yu, S., Lee, C., Khadpe, P., Ibrahim, L., & Jurafsky, D.
  (2025). *ELEPHANT: Measuring and understanding social sycophancy in LLMs.*
  arXiv:2505.13995.
- **License:** CC0 1.0 Universal (see `LICENSE`).

Each row is one AITA post pair: `original_NTA_post`, the GPT-4o `flipped_post`,
and per-model verdict columns from the paper's own runs.
